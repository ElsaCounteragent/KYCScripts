KYC / Review Workflow Userscripts (Sanitized JavaScript Demos)

I built a small collection of JavaScript userscripts to support repetitive, form-based review workflows. The scripts are local browser helpers designed to reduce manual copy-paste work, catch simple data-format issues, and make recurring checks easier to follow.

They do not make compliance decisions, do not store case data externally, and do not replace human review. The public versions are sanitized demos: employer-specific URLs, internal selectors, client data, and confidential workflow logic have been removed or replaced with generic placeholders.

Focus areas:
- Form field validation and consistency checks
- Checklist tracking for repetitive review steps
- Highlighting missing or inconsistent fields
- Structured note preparation for manual review
- Local-only browser automation using Tampermonkey

Tech: JavaScript, Tampermonkey, DOM manipulation, userscripts, form validation.
